## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Ramsagar705/Ramsagar-portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd Ramsagar-Portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
